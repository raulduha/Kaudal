# Biblioteca de Plantillas Kaudal (descargable / abierta)

Recetas de agentes y workflows, abiertas para inspección y descarga. **No contienen datos ni secretos de clientes.**

## Agentes (`agents/`)
- `_plantilla.json` — esqueleto base para crear un agente nuevo.
- `soporte-cliente.json` — atención por WhatsApp/web.
- `ventas-sdr.json` — califica leads y agenda reuniones.
- `cobranza.json` — recordatorios de pago amables.
- `documentos.json` — clasifica y extrae datos de archivos.
- `marketing-contenido.json` — motor del bot de marketing.

## Workflows (`workflows/`)
- `reclamo-postventa.json` — flujo de reclamos con revisión humana.
- `cobranza-whatsapp.json` — secuencia de cobranza.
- `onboarding-lead.json` — captura y calificación de leads.

Todas siguen `schemaVersion` para compatibilidad. Ver `docs/08-contenido-descargable.md`.
