# docs/rutas/ — Bitácora de rutas e2e

Cada agente que llevas de punta a punta se documenta acá, una ruta por archivo:
`ruta-01-<nombre>.md`, `ruta-02-<nombre>.md`, …

Plantilla por ruta: qué hace · canal · tools · evals · precio (calculadora) · despliegue · aprendizajes · estado (piloto/vivo).

La Ruta 1 (flagship, nativa en Mastra) está especificada en `docs/17-ruta-e2e-mastra.md`. Cuando la construyas, crea aquí `ruta-01-...md` con lo aprendido.
